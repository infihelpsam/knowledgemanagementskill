# Third-party dependencies

Backend libraries and container images retain their respective licenses. Before distributing or hosting a commercial release, inventory the exact resolved packages, images and optional embedding model weights; preserve required notices and review model use restrictions. No third-party source/model weights are bundled in release ZIPs. requirements-tested.txt records the tested Python environment once validation completes; it is not a complete SBOM or vulnerability audit.

The repository LICENSE is an intentional owner-selection placeholder. Optional sentence-transformers model weights are downloaded separately. Do not infer a model license from the Python package license.
